## Блок П: Персонаж (Roblox-style 3D)

| # | Шаг | Что делаем | Тест |
|---|-----|-----------|------|
| П1 | Three.js + React Three Fiber | Установка `@react-three/fiber @react-three/drei three` | `pnpm dev` → нет ошибок импорта |
| П2 | Canvas-компонент | `<Canvas>` на странице профиля, пустая сцена с камерой | Открыть `/profile` → видно тёмный фон WebGL |
| П3 | «Земля» — пол и свет | Plane + ambientLight + directionalLight | Видно освещённую плоскость под персонажем |
| П4 | Торс (BoxGeometry) | Прямоугольник-тело, цвет `#7C4DFF` | Видно фиолетовый куб по центру |
| П5 | Голова (BoxGeometry) | Куб-голова поверх торса, цвет кожаный | Видно два куба — тело + голова |
| П6 | Руки (BoxGeometry × 2) | Два вытянутых куба по бокам торса | Видно руки |
| П7 | Ноги (BoxGeometry × 2) | Два вытянутых куба снизу торса | Полный человечек из кубов! |
| П8 | Глаза (маленькие BoxGeometry × 2) | Два белых кубика с чёрными зрачками на голове | Видно глаза |
| П9 | Анимация — покачивание | `useFrame` → sin(time) для рук/ног | Персонаж слегка двигается |
| П10 | Вращение камеры | OrbitControls → можно покрутить персонажа мышкой | Потянуть мышкой → камера вращается |
| П11 | Пропорции как в Roblox | Подогнать размеры: голова=1×1×1, торс=1×1.2×0.6, руки=0.4×1×0.4, ноги=0.5×1×0.5 | Визуально похож на роблокс-персонажа |
| П12 | Компонент `Character` | Вынести всю модель в `src/components/character.tsx` | Импорт на других страницах, переиспользование |
| П13 | Пропсы: `outfit?`, `hat?`, `color?` | Хук `useCharacter({ outfit, hat, color })` → меняет текстуры/цвета | Передать `color="red"` → персонаж красный |
| П14 | Уровень на странице профиля | Надпись «Уровень: 1» + опыт из БД (пока 0) | Видно «Уровень: 1» рядом с персонажем |
| П15 | Прогресс-бар опыта | Bar под уровнем, заполняется от `xp` | `xp=50, max=100` → бар на 50% |

> **Дальнейшее масштабирование**: шаги П12-П13 — фундамент для кастомизации. Добавить шляпу = новый пропс. Добавить костюм = новый пропс. Каждый предмет — отдельный компонент, подключается через пропсы `Character`.

## Блок М: Мобильная оптимизация (mobile-first)

| # | Шаг | Что делаем | Тест |
|---|-----|-----------|------|
| М1 | viewport meta | `<meta name="viewport" content="width=device-width, initial-scale=1, maximum-scale=1, user-scalable=no">` | Chrome DevTools iPhone 14 → без горизонтального скролла |
| М2 | Дашборд: без скролла | Все элементы на одном экране: приветствие, персонаж (мини), Empty State, 2 кнопки, профиль | `100vh`, не скроллится на 375×812 |
| М3 | Профиль: без скролла | Персонаж + уровень + прогресс + «На главную» — на одном экране | `100vh`, всё видно без скролла |
| М4 | Логин/Регистрация: по центру | Карточка по центру экрана, не уезжает | На 375px — карточка не обрезана |
| М5 | Нижняя навигация (Bottom Nav) | 4 иконки внизу: Главная, Друзья (серым), Лидерборд (серым), Профиль | Фиксирована снизу, не скроллится |
| М6 | `safe-area-inset-bottom` | Отступ для iPhone с чёлкой | На iPhone — контент не под системной полосой |
| М7 | Tailwind breakpoints | `sm:` (640px) и `md:` (768px) для планшетов — контент шире, но без скролла | iPad: кнопки в ряд, персонаж крупнее |

> **Правило для всех страниц**: контент = `min-h-screen` или `h-screen`, flex, без overflow. Всё должно помещаться на одном экране телефона (375×812). Скролл — только если контента объективно больше (список комнат, список задач).
