# Focus Champ — Описание экранов

## Карта экранов MVP

```
┌──────────┐    ┌──────────┐
│ /register │    │ /login   │
└────┬─────┘    └────┬─────┘
     │               │
     └───────┬───────┘
             │ (после входа)
             ▼
      ┌─────────────┐
      │ /dashboard   │ ← Главный экран
      └──┬───┬───┬──┘
         │   │   │
    ┌────┘   │   └────┐
    ▼        ▼        ▼
┌────────┐ ┌──────┐ ┌─────────┐
│/create │ │/join │ │/profile │
└───┬────┘ └──┬───┘ └─────────┘
    │         │
    └────┬────┘
         ▼
    ┌──────────┐
    │/room/[id]│ ← Игровой экран
    └──────────┘
```

## Экран 1: Регистрация `/register`

### Состояние: пустая форма
```
┌──────────────────────────────────┐
│          Focus Champ             │
│                                  │
│  ┌──────────────────────────┐   │
│  │  Логин                   │   │
│  └──────────────────────────┘   │
│  ┌──────────────────────────┐   │
│  │  Пароль                  │   │
│  └──────────────────────────┘   │
│  ┌──────────────────────────┐   │
│  │  Повторите пароль        │   │
│  └──────────────────────────┘   │
│                                  │
│  ┌──────────────────────────┐   │
│  │   Зарегистрироваться     │   │
│  └──────────────────────────┘   │
│                                  │
│   Уже есть аккаунт? Войти       │
└──────────────────────────────────┘
```

### Валидация
- Логин: мин 3, макс 20 символов, латиница + цифры + `_`
- Пароль: мин 6 символов
- Проверка совпадения паролей
- Проверка уникальности логина (асинхронно)

### Состояния
- **Загрузка**: кнопка disabled + лоадер
- **Ошибка**: красный alert под формой (например, «Логин уже занят»)
- **Успех**: редирект на `/dashboard`

## Экран 6: Комната `/room/[id]` — Игровой экран

Это главный экран приложения. Делится на зоны:

### Верхняя часть: заголовок
```
┌──────────────────────────────────┐

│            Код: ABC123    ⚙️     │
│            День 5                │

```
┌──────────────────────────────────┐

### Пустое состояние (Empty State)
Используется, когда данных нет (нет комнат, нет друзей, нет очков):
- Иконка
- Заголовок: «Пока пусто»
- Подзаголовок с призывом к действию
- Кнопка CTA
