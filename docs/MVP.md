# Focus Champ — MVP (Фаза 1: Core)

## Цель MVP

Протестировать гипотезу: **люди будут конкурировать в ежедневных привычках, если AI убирает проблему доверия**.

MVP — это минимальный работающий продукт с AI-верификацией, который можно дать первым 10-20 пользователям.

---

## Что входит в MVP

### Модуль 1: Аутентификация
| Функция | Описание | Приоритет |
|---------|----------|-----------|
| Регистрация | Логин + пароль (без email) | P0 |
| Вход | По логину и паролю | P0 |
| Выход | Кнопка «Выйти» в профиле | P0 |
| Сессия | JWT, хранение в httpOnly cookie | P0 |
| Middleware | Защита роутов (редирект на /login если не авторизован) | P0 |

**НЕ входит:** восстановление пароля, email-подтверждение, OAuth, 2FA.

### Модуль 2: Комнаты (Rooms)
| Функция | Описание | Приоритет |
|---------|----------|-----------|
| Создание комнаты | Название + список задач с очками + флаг «требуется подтверждение» | P0 |
| Код комнаты | 6-значный буквенно-цифровой код, уникальный | P0 |
| Присоединение | Ввод кода → присоединение к комнате | P0 |
| Список комнат | На дашборде: активные комнаты пользователя | P0 |
| Просмотр комнаты | Список задач, участники, текущий день, очки | P0 |
| Минимум 2 участника | Комната активна, даже если 1 участник, но соревнование имеет смысл от 2 | P0 |

**НЕ входит:** удаление комнаты, редактирование задач после создания, кик участника, приглашение из друзей.

### Модуль 3: Игровая механика
| Функция | Описание | Приоритет |
|---------|----------|-----------|
| Игровой день | Каждый день — новый CompetitionDay | P0 |
| Отметка выполнения | Кнопка «Выполнил» для задач без подтверждения | P0 |
| Начисление очков | Автоматически при отметке (или после AI-верификации) | P0 |
| Подсчёт за день | Сумма очков по всем задачам за день | P0 |
| Победитель дня | Игрок с наибольшей суммой очков | P0 |
| Завершение дня | Автоматическое в 00:00 UTC (Vercel Cron) | P0 |

**НЕ входит:** длительность соревнований (MVP: бесконечно), общий победитель, статистика.

### Модуль 4: AI-верификация
| Функция | Описание | Приоритет |
|---------|----------|-----------|
| Загрузка скриншота | Через Uploadthing, превью перед отправкой | P0 |
| Анализ Gemini | Отправка скриншота в Gemini 2.5 Flash Vision API | P0 |
| Структурированный ответ | Gemini возвращает JSON: verified, confidence, reasoning | P0 |
| Авто-начисление | verified=true → очки начислены, verified=false → отклонено | P0 |
| Отображение результата | ✅ Подтверждено / ❌ Отклонено с причиной | P0 |

**НЕ входит:** оспаривание, peer-review, видео-верификация, интеграции с API (Health, Fit).

## Промпт для Gemini Vision (AI-верификация)

```
Ты — система автоматической проверки выполнения ежедневных задач. 
Тебе покажут скриншот. 

Задача: "{task_title}"
Контекст: пользователь должен был {task_description}.

Проанализируй скриншот и ответь СТРОГО в формате JSON:
{
  "verified": true/false,
  "confidence": 0.0-1.0,
  "extracted_data": { /* ключевые данные со скриншота */ },
  "reasoning": "краткое обоснование на русском"
}

Важно:
- Если скриншот явно поддельный/нерелевантный → verified: false, confidence: 0.0
- Если данных недостаточно → verified: false, confidence: <0.5
- Проверяй дату на скриншоте: она должна быть за сегодня или вчера
- Для трекера сна: проверь общее время сна
- Для экранного времени: проверь суммарное время и категории приложений
```

## Архитектура MVP (упрощённая)

```
/pages (или /app в Next.js 15)
├── /login          — страница входа
├── /register       — страница регистрации
├── /dashboard      — главный экран (список комнат)
├── /room
│   ├── /create     — создание комнаты
│   ├── /join       — присоединение по коду
│   └── /[id]       — комната (игровой экран)
├── /profile        — профиль
└── /api
    ├── /auth/[...nextauth]  — NextAuth
    ├── /rooms               — CRUD комнат
    ├── /tasks               — отметка выполнения
    ├── /verify              — AI-верификация скриншота
    ├── /upload              — загрузка файлов (Uploadthing)
    └── /sse/[roomId]        — Server-Sent Events
```

## Ключевые API-эндпоинты MVP

| Метод | Путь | Описание |
|-------|------|----------|
| POST | `/api/auth/register` | Регистрация |
| POST | `/api/auth/login` | Вход (NextAuth) |
| POST | `/api/rooms` | Создать комнату |
| GET | `/api/rooms` | Список моих комнат |
| GET | `/api/rooms/[id]` | Детали комнаты + текущий день |
| POST | `/api/rooms/join` | Присоединиться по коду |
| POST | `/api/tasks/[id]/submit` | Отметить выполнение (без AI) |
| POST | `/api/tasks/[id]/verify` | Отправить скриншот на AI-проверку |
| GET | `/api/sse/[roomId]` | Подписка на real-time события |

## Ограничения MVP (сознательные упрощения)

1. **Один тип верификации** — только скриншоты (не видео)
2. **Один AI-промпт** — универсальный, не кастомизируется под тип задачи
3. **Без anti-spoofing** — не проверяем метаданные скриншота, не детектим подделки
4. **UTC-дни** — день заканчивается в 00:00 UTC, нет часовых поясов
5. **Без модерации** — нет жалоб на комнаты/пользователей
6. **Без уведомлений** — только SSE в открытом браузере, нет push/email
7. **Без удаления** — комнаты, задачи, аккаунты нельзя удалить через UI
8. **До 5 участников** — тестируем на малых группах
9. **До 10 задач** — в одной комнате

## Критерии успеха MVP

| Метрика | Цель |
|---------|------|
| Пользователи | 10-20 активных |
| Комнаты | 3-5 созданных |
| Дней сыграно | 7+ (минимум неделя) |
| AI-верификаций | 10+ скриншотов проверено |
| Точность AI | >80% корректных вердиктов (по опросу пользователей) |
| Возвращаемость | >50% пользователей возвращаются на 2+ день |
