# Design System v1.0

example photo/design_v1.png

## Проект

**Рабочее название:** Habit Battle

**Концепция:**
Соревнование пользователей в выполнении ежедневных привычек и целей с использованием AI-проверки доказательств выполнения задач.

---

# Дизайн-концепция

## Основная идея

Приложение должно создавать ощущение:

* соревнования
* прогресса
* саморазвития
* RPG-прокачки персонажа
* ежедневного вовлечения

## Референсы

* Apple Fitness Competition
* Duolingo
* Habitica
* Strava
* Discord
* Supercell UI

---

# Визуальный стиль

## Тема

Dark Theme First

Интерфейс должен быть ориентирован на использование вечером и в течение дня без высокой нагрузки на глаза.
